# RHC案例与分析设置

| 项目 | 本教程的设置 |
| --- | --- |
| 数据与研究 | SUPPORT公开观察性队列，5735位重症患者。[原始研究](https://pubmed.ncbi.nlm.nih.gov/8782638/) · [患者摘要与数据来源](public-data.html) |
| 研究起点与入组 | 首次符合SUPPORT入组标准；原研究纳入在48小时后仍存活且住院的患者。 |
| 处理 $A$ | 首24小时是否接受右心导管检查（RHC），原字段`swang1`；接受2184人，未接受3551人。 |
| 结局 $Y$ | 入组后30日全因死亡，原字段`dth30`；死亡1918人，存活3817人。第30日死亡计入结局。 |
| 估计目标 | 在共同基线人群上，接受RHC与未接受RHC的30日死亡风险标准化差；人群平均使用全体5735人的基线分布。 |
| 调整变量 | 第1–7章主要使用原字段sex；第8章扩展为sex、年龄、race及12项既往病史。 |
| 初始拟合 | $g$预测接受RHC的概率；$Q$用基线与处理预测死亡风险。多变量版本采用带截距的主效应logistic回归。 |
| 变量编码 | 15项基线变量编码为17列设计矩阵，$Q$另加处理列。年龄按全样本均值与以$n$为分母的标准差标准化；race以white为参考。 |
| 计算过程 | g-computation → AIPW一步校正；TMLE沿EIF确定的方向更新$Q$，再标准化。各章复用同一份患者记录。 |
| 因果解释 | ATE解释需要一致性、给定基线后的可交换性及正值性；时间起点、处理窗与入组选择共同界定适用人群。 |
