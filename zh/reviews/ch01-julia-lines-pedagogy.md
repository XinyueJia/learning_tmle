## 输入与最先发生的计算必须具体

CSV 是八行聚合表，一行是一种 X/A/Y 组合，n 表示这种记录出现多少次，不是八个人。CH01 使用各格 y、n、p 和总人数/边际风险；X/A 只用于保留同一数据的组标签，本讲不拿它们作因果调整。

`case_data(...)` 是项目自己的数据准备函数，不能仅译为“读取数据”就跳过其接口。新稿至少应展示本讲拿到的对象形状及字段：`data.n=200`；`data.cells` 为八格的有序集合；每格 `c.y` 为 0/1、`c.n` 为人数、`c.p=c.n/200`；`data.marginal_risk=116/200=.58`。不要求第一讲解释该准备函数为以后讲次生成的全部对象。

尤其现有 `risk = data.marginal_risk` 只是取出已经算好的风险，不是在该行才统计 116 人。应实际给出八格的 `n×y` 为 `0,56,0,16,0,4,0,40`，相加 116 后除以 200；随后再说明函数复用这个结果。不能让读者以为 `.58` 来自未知真分布、八个 y 的普通平均或程序内写死的答案。

## 当前 CH01 定义所需解释

| 当前写法 | 零基础读者需要知道什么 | 必须能在本例核对的结果 |
| --- | --- | --- |
| `# ...` | 注释帮助人读，程序不将其作为运算执行 | 注释中的中文不会作为结果打印 |
| `function mean_if(data)` | 定义一个可重复使用的步骤；`data` 是接收输入的局部名字；定义时不会自动计算当前数据 | 后面的 `mean_if(data)` 才调用这个步骤 |
| `risk = data.marginal_risk` | `=` 为赋值/绑定名字，非待证明的恒等式；点号取带名字对象中的字段；下划线属于变量名 | risk 得到 .58，不修改原记录 |
| `[c.y - risk for c in data.cells]` | 方括号建立向量；`for c in ...` 依次取每一格，c 只是当前格的临时名字；逐格计算并收集结果 | 八个值按原格序为 `[-.58,.42,-.58,.42,-.58,.42,-.58,.42]`，不是两人也不是 200 个新数 |
| `values[i]` | 方括号读取第 i 项；Julia 的位置从 1 开始；位置编号不等于 y 的 0/1 标签 | 第一格 y=0 却用 `values[1]` 读取；第二格 y=1 用 `values[2]` |
| `enumerate(data.cells)` 与 `(i,c)` | 每次同时得到从 1 开始的位置 i 与当前格 c；二者用来把同一格概率与同一位置的函数值配对 | 第一项为 `(24/200)×(-.58)`，第二项为 `(56/200)×.42` |
| `sum(c.p * values[i] for ...)` | `*` 是普通数值相乘；依次形成每格“概率×函数值”，sum 将这些贡献相加；这里不是再计算一次普通 y 均值 | 合并 y=0 与 y=1 后为 `(84/200)(-.58)+(116/200)(.42)=0`，机器输出可能有微小舍入误差 |
| `(; risk, values, mean=...)` | 构造带字段名字的结果；risk/values 用原名字存入，mean 字段存入刚算的加权平均；不是三次打印或三个独立返回动作 | 调用者可用 `result.risk`、`result.values`、`result.mean` 分别读取 |
| 最后一行表达式与 `end` | 现有函数没有写 `return`，Julia 会返回最后计算的表达式；end 结束函数。若新稿使用显式 return，须说明它把结果交回调用处，不等于打印 | 得到一个结果对象后，才由 lesson 输出其字段 |

若新样板改成更展开的赋值与循环，应按实际新代码逐行讲，不必为了讲解而保留最密集的一行。必要的是输入、当前值、执行动作和统计作用能够对得上，而非逐个词换成中文。

## 当前 lesson 调用所需解释

| 当前写法 | 要解释的操作与界限 |
| --- | --- |
| `joinpath(@__DIR__, "..", ...)` | 字符串写在引号中；joinpath 拼接路径；`@__DIR__` 指当前脚本所在目录；每个 `".."` 上移一级。分别指向 EIFCase.jl 与 case-study/followup-counts.csv，说明为何两个目录应一起保留 |
| `data = case_data(...)` | 调用准备函数，接收它返回的数据对象；名字 data 并不是 Julia 预设的一张表 |
| `result = mean_if(data)` | 将同一数据交给上面的函数，接收带名字的结果；可在这一步列出 risk=.58、values 八项、mean 近零 |
| `sum(c.n * c.y for c in data.cells)` | 按人数合并二元结局，得到事件数 116；不先展开成 200 行仍能得到相同平均 |
| `@printf("...", ...)` | 格式串与后续数值按顺序对应；打印是展示，非重新估计。`@` 在此调用格式化打印工具，不必先学习宏的内部实现 |
| `%.0f`、`%d`、`%.6f`、`%.3g`、`\n` | 分别显示零位小数、整数、六位小数、三位有效数字与换行；`0.580000` 和 `.58` 为同一数值，不能把输出位数当估计精度。最终近零也不必恰好打印成字符 0 |
| `for y in 0:1` / `end` | `0:1` 在此依次取 0、1 两个标签；循环会把内部打印动作执行两次，不是取第 0 项数组。此处 y 是为了显示两个可能输入值，不是在重新遍历两个人 |
| `y - result.risk` | 先取结果字段，再从选定 y 减去它；解释对应未住院/住院的 −.58/.42，而非电话方案的风险差 |
| `result.mean` | 是上面概率加权的函数平均；与 data 中的边际住院均值不同。前者近零、后者 .58，各自准确命名 |

本讲本来的预期输出应就地可见：住院数 116 / 200，风险 .580000；y=0/1 的函数值 −.580000/.420000；经验概率加权平均在舍入精度内为零。不提前要求读者理解方差、SE、ATE 权重、offset 或更新系数。
