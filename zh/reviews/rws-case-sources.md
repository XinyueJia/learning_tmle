# 药品上市后RWS教学案例：设计术语与来源核验

核验日期：2026-10-15。范围：匿名已上市药物的合成观察性研究设定与识别边界。已读`zh/docs/COURSE_CONTRACT.md`和`zh/docs/SOURCES.md`；后者的EIF来源继续适用，本记录不重新审查EIF。英文使用British spellings。本记录没有审查真实药品的临床效果，也没有将合成数据称为真实世界证据。

## 可直接采用的教学设定

建议题名为“已上市抗肿瘤药A相对于活性对照药B的真实世界疗效再评价：合成案例”。真实世界研究（real-world study, RWS）是案例的应用背景；200条记录均为教学合成记录。按FDA的定义，日常医疗中常规收集的数据才是RWD，分析这些数据得到的临床证据才是RWE。因此应写“模拟真实世界研究的数据结构”，不能写“已从真实医院获得RWE”。[FDA：Real-World Evidence，Definitions](https://www.fda.gov/science-research/science-and-research-special-topics/real-world-evidence)

以下是本教程为了维持二元$O=(X,A,Y)$而选择的简化方案，不是文献提供的肿瘤临床方案或风险数字：

| 方案要素 | 建议表述 |
| --- | --- |
| 目标人群 | 在同一适应证、同一治疗线次下，临床上两种药物均可考虑、并符合预先规定基线资格的患者。目标只覆盖这些新使用者，不外推至所有肿瘤患者。 |
| 新使用者 | 在预先规定且可观察的回溯窗口内未使用研究药A或对照药B，并于索引日开始其中一种。这里的“新”不是从未接受过任何抗肿瘤治疗。窗口长度应由具体药物和数据背景确定；本教程不虚构通用的临床标准。 |
| 时间零点 | 每位患者首次符合上述资格并开始A或B的日期。资格判定、用药分组与随访起点对齐；基线$X$在开始用药前确定。 |
| 暴露 | 数学变量$A=1$表示开始药物A，$A=0$表示开始药物B；后续叙述需区分“药物A”和变量$A$。 |
| 疗效结局 | $Y=1$表示开始用药后12个月内出现预先定义的疾病进展或全因死亡，$Y=0$表示已确认到该时点未发生这一复合终点。该终点方向为不良；疾病进展判定规则必须预先说明。 |
| 基线简化 | $X=0$为高基线预后风险，$X=1$为低基线预后风险。它是人工压缩后的教学分层，不是任何已验证的临床评分。真实研究需要依据问题选择充分的基线混杂因素，不能假定一个二元评分天然足够。 |
| 因果问题 | 在同一目标人群中，若开始药物A与若开始药物B，12个月进展或死亡的风险相差多少；风险差取A减B。 |
| 后续用药 | 以初始用药分组，在停药、换药后仍继续观察结局。所求是开始用药策略的效应；不是假设所有人连续12个月坚持原药的效应。 |
| 随访简化 | 合成模型直接假定每人的12个月结局完整、准确可得；死亡已计入结局。该假定不等于按将来的完整随访筛选患者。 |

固定机制中$Q(1,0)>Q(0,0)$且$Q(1,1)>Q(0,1)$，标准化风险差为$+0.20$。这是本教程数值模型的结果：在上述识别条件下，药物A的这一不良疗效终点风险比B高20个百分点。不能称为“获益20个百分点”，也不能据此判断A相对B的毒性、安全性、总体获益风险或任何真实药品的效果。安全性再评价需另设明确的不良事件终点及数据；本轮$Y$不提供该结论。

“12个月内进展或死亡的风险”是固定时点二元终点，不要把该二元分析输出直接称为中位无进展生存期、风险比（hazard ratio）或完整生存曲线。该命名边界来自当前数据与估计目标的定义。

## 已核验的原始设计文献

### Hernán & Robins（2016）：目标试验、时间零点与效应

[原文全文：Using Big Data to Emulate a Target Trial When a Randomized Trial Is Not Available](https://pmc.ncbi.nlm.nih.gov/articles/PMC4832051/)，*American Journal of Epidemiology* 183(8):758–764，[DOI](https://doi.org/10.1093/aje/kwv254)。已在线读取正文相关节及Table 1。

支持范围：Table 1规定目标试验方案要素；“Assignment procedures”要求充分基线混杂调整；“Defining time zero”要求资格、策略起始与结局计数起点协调。“Causal contrast(s) of interest”及“Analysis plan”区分初始分配与持续按方案效应。观察性新使用者比较只能称为意向治疗分析的类似对应，不能直接声称具有随机试验的意向治疗效应。持续治疗效应及失访可能需基线后因素与g-methods。这里采用的12个月、匿名抗肿瘤药和二元风险层不是该论文的临床设定。

### Yoshida, Solomon & Kim（2015）：活性对照与新使用者

[原文全文：Active-comparator design and new-user design in observational studies](https://pmc.ncbi.nlm.nih.gov/articles/PMC4486631/)，*Nature Reviews Rheumatology* 11(7):437–441，[DOI](https://doi.org/10.1038/nrrheum.2015.30)。已在线读取“Active comparator design”“New user design”及局限节。

支持范围：比较相同或类似适应证的活性药物，并从开始用药建立队列，可改善可比性、时间起点和用药前协变量测量；设计有助于减少适应证混杂及部分时间相关偏倚，但不保证消除混杂。该文的疾病与数值例子不用于本教程。

Lund, Richardson & Stürmer同年的同主题论文已检索到[PMC记录](https://pmc.ncbi.nlm.nih.gov/articles/PMC4778958/)，但本次全文访问遇到验证页；因此没有把其具体正文论断列为已全文核验依据，不需要为本次教学标签额外依赖该文。

## FDA资料：数据适用性与结局缺失

[官方最终指南页面](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/real-world-data-assessing-electronic-health-records-and-medical-claims-data-support-regulatory)，[已在线打开的39页PDF](https://www.fda.gov/media/152503/download)：*Real-World Data: Assessing Electronic Health Records and Medical Claims Data to Support Regulatory Decision-Making for Drug and Biological Products*，封面日期July 2024。以下页码为印刷页，PDF页序需加3。

- §IV.C，p.11：理解缺失原因、论证假设，并评估结果的敏感性。
- §IV.D，pp.12–13及§V.D：区分概念定义、数据中的操作性定义与验证，适用于暴露、结局和协变量。
- §V.D.4，p.26：死亡信息可能漏记，不能简单把失联者排除或全部当成死亡。
- §V.E.1，pp.26–27：评价数据是否充分记录重要混杂因素，披露未测量或测量不佳者。

该指南支持研究数据的适用性检查，不证明当前合成模型具备监管用途，也不为任何合成风险背书。

## 本教程须保留的识别边界

由上述设计原则应用到本模型，可得以下限定；这些是本项目的建模判断，而不是新增临床证据：

1. **识别不由估计器保证。** 一致性（consistency）、给定$X$的条件可交换性（conditional exchangeability）及正值性（positivity）仍是从观测标准化量解释因果风险差的条件。活性对照、新使用者、AIPW和TMLE均不自动保证这些条件。
2. **二元$X$的充分性是教学假设。** 实际肿瘤研究应考虑病种和线次所需的基线病情、功能状态、既往治疗及其他混杂因素；在本课不得暗示仅高低风险两个标签就已解决真实适应证混杂。
3. **不按后续坚持用药筛人。** 不以“坚持原药12个月”或“用药后有完整12个月医疗记录”作为本模型的入组资格；这样的选择利用了基线后信息，改变了原来问题。
4. **现有EIF不处理结局缺失。** $O=(X,A,Y)$默认$Y$已知。失访时，现有暴露权重$1/g(X)$不能自动修复$Y$的缺失；需扩展观测结构、缺失/删失机制和相应识别及估计方法，不能把未知$Y$编码为0。
5. **疗效与安全性分别定义。** 进展/全因死亡的复合终点不提供特定药物不良反应的发生情况或归因。若后续增加安全性终点，应独立定义事件、时间窗、观测与效应目标。
