## 从原estimand独立推导数值基准

本章标准化目标是两个干预风险之差：

```
ψ = p_X(0)[Q(1,0)−Q(0,0)]
  + p_X(1)[Q(1,1)−Q(0,1)]。
```

原p_X=(.5,.5)，Q(1,0)=.80、Q(0,0)=.70、Q(1,1)=.50、Q(0,1)=.20。因此风险1=.65，风险0=.45，ψ=.20。

### 仅高估处理风险Q(1,0)

将该项加δ，其余三Q、人群权重及处理机制均不改：

```
ψ_new−ψ
= {.5[(.80+δ)−.70]+.5(.50−.20)}
  −{.5(.80−.70)+.5(.50−.20)}
= .5δ。
```

δ=.02时，新风险1=.5×.82+.5×.50=.66，风险0仍.45，ATE=.21，目标误差+.01=+1个百分点。

### 仅高估对照风险Q(0,0)

同样将该项加δ而保持其他部分：

```
ψ_new−ψ
= {.5[.80−(.70+δ)]+.5(.50−.20)}
  −{.5(.80−.70)+.5(.50−.20)}
= −.5δ。
```

δ=.02时，风险0=.5×.72+.5×.20=.46，风险1仍.65，ATE=.19，目标误差−.01=−1个百分点。

这里.02是**条件风险增加2个百分点**，.01是**总体风险差改变1个百分点**；不是2%的相对变化，也不是2%的人被替换。正负号来自处理风险减对照风险，共同系数.5来自目标人群中X=0的权重，与处理分配概率g(0)=.2不同。

本计算在固定p_X的目标中对Q是线性的，所以差值关系精确成立；不能泛化为所有分布误差或任意目标的有限一步精确一阶式。每项新Q仍在[0,1]，改变条件Bernoulli概率须同时使该条件组中Y=0概率相应减少；不能理解为整体记录概率增加.02而不减别处。

## 这两个误差例子与完整IF的边界

- 两例描述指定条件风险坐标的误差怎样传给plug-in目标；+.5和−.5是该坐标的斜率，.01是给定δ的实际目标误差。这些数均不是完整ATE IF函数，也不能把其绝对值叫作IF的值。
- 一套给定拟合Q产生的目标误差，是该套拟合值相对真目标的确定性差。统计偏差（bias）通常指估计量在重复抽样中的平均误差；尚未给出拟合算法和抽样机制时，不应把本例直接说成已计算该估计器的统计bias。可以说“这次拟合值带来的误差”或明确当前bias采用总体固定拟合的定义。
- 完整IF给可能观测记录O=(X,A,Y)赋值，统一表示目标沿模型允许的微小记录分布变化的一阶响应。改变人群权重、处理分配或条件风险会对应不同合法方向；分布总质量仍为1，不可单独增加记录概率而不减少别处。
- 数值坐标例子是对“分布拟合错了会影响目标”的入口，随后需要明确从少数坐标转向所有允许分布方向的动机。不能说看完两个Q例子就已证明完整IF表示、存在性或效率。
- IF的值不是个人因果效应、干预后个人结局变化或有限样本中加入一条记录的精确变化。它也不是所有拟合误差的一个固定通用乘数；方向和路径尺度必须明确。

## 通往估计误差的有条件联系

独立敏感性定义之后，才可预告统计用途：当合适的估计规则满足渐近线性及相应正则/收敛条件时，估计误差的一阶主要部分可由观测贡献的平均表示。其余项需在抽样误差尺度上足够小；拟合IF、同一数据重复使用及nuisance误差需要额外控制。

因此，以下说法不应出现：任意估计量误差都精确等于IF平均；把拟合残差求平均即可自动消掉有限样本偏差；给出敏感性函数即自动有可靠标准误/区间；方程经验平均为零便证明真偏差为零。第0章可暂不用估计误差展开式，但条件预告不能删除。

## efficient的含义与模型限制

统计模型规定允许哪些分布及方向；目标与模型一起决定效率比较。EIF在此指模型内表示全部合法方向的典范梯度，不是只表示两个Q坐标的数值。是否存在适合的一阶表示并非所有目标的无条件事实；第0章仅导读后续在有限模型验证的对象。

效率下界针对给定模型中的正则估计量（regular estimators）的大样本一阶波动；达到界仍需合适方法与条件。它不是计算速度、个人因果效应、任意估计器的有限样本排名或未测混杂的修复保证。不要从“最小的函数长度”跳成任意样本中误差最小；函数平方范数与渐近方差之间的桥梁后续才建立。
