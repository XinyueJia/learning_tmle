## 从定义独立核对

### 1. 截距参数、score、信息量与目标 IF

固定 Bernoulli 分布，假设 `0<μ<1`，令 `β=logit(μ)`。单观测对数似然为

\[
\ell_\beta(y)=y\beta-\log(1+e^\beta),\qquad
\frac{d\mu}{d\beta}=\mu(1-\mu).
\]

因此

\[
s_\beta(y)=\frac{\partial\ell_\beta(y)}{\partial\beta}=y-\mu,
\qquad I_\beta=E_P[s_\beta(Y)^2]=\mu(1-\mu).
\]

这里的信息量按单观测定义，不能混入全样本 `nI`。在这个正则一维 Bernoulli 模型中，logit 参数的有效 IF 为

\[
D^\beta_P(y)=I_\beta^{-1}s_\beta(y)
=\frac{y-\mu}{\mu(1-\mu)}.
\]

同一模型中，均值目标的 IF 则由链式法则给出

\[
D^{\mathrm{mean}}_P(y)
=\frac{d\mu}{d\beta}D^\beta_P(y)
=\mu(1-\mu)\frac{y-\mu}{\mu(1-\mu)}=y-\mu.
\]

应把 `I^{-1}s` 归属到此模型下的有效参数 IF，或满足正则条件的极大似然估计量的 IF；不宜称为任意估计量的通用 IF。此例二元分布只有一个自由概率，因此与均值的非参数推导一致。

若改用均值自身作为坐标，直接对

\[
\ell_\mu(y)=y\log\mu+(1-y)\log(1-\mu)
\]

求导得到

\[
s_\mu(y)=\frac{y}{\mu}-\frac{1-y}{1-\mu}
=\frac{y-\mu}{\mu(1-\mu)},\qquad
I_\mu=\frac1{\mu(1-\mu)}.
\]

于是 `I_μ^{-1}s_μ=y−μ`。这个换坐标例子直接解释：score 取决于用于描述分布变化的参数；均值目标没有改变，其 IF 也没有改变。

### 2. 从参数 score 到路径 score

沿 `β_t=β+t` 的路径，

\[
S(Y)=\left.\frac{d}{dt}\log p_{\beta+t}(Y)\right|_{t=0}=Y-\mu,
\qquad
\left.\frac{d}{dt}\mu_t\right|_{t=0}=\mu(1-\mu).
\]

将上一节得到的均值 IF 放入路径关系：

\[
E_P[D^{\mathrm{mean}}_P(Y)S(Y)]
=E_P[(Y-\mu)^2]=\mu(1-\mu).
\]

这与直接导数吻合。若使用既有符号 `r=μ`、`c=1−μ`，右侧为 `rc=μc`，应当就地回看 `c` 是存活概率。此处步长是 logit 坐标的增量；它与前文点替换比例同写 `t`，但定义不同，需要明确交代。可将新路径写成 `P_{β+t}`，使参考对象一目了然。

更一般地，二元支持上的任一可微概率路径满足 `\dot p_0+\dot p_1=0`，且 `S(y)=\dot p_y/p_y`，所以

\[
E_P[(Y-\mu)S(Y)]
=\sum_y(y-\mu)\dot p_y
=\dot p_1-\mu(\dot p_0+\dot p_1)=\dot p_1=\dot\mu.
\]

这一步可作为简短技术说明，说明该候选 IF 不仅适用于一条 logit 路径，也适用于二元模型中所有可微方向。

### 3. 原有点替换路径的 score

沿 `P_t=(1−t)P+tδ_z`，有 `\dot p_y=1{y=z}−p_y`，因此

\[
S_z(y)=\frac{\mathbf1\{y=z\}}{p_y}-1
=\frac{\mathbf1\{y=z\}}{p_z}-1.
\]

最后两个式子相同，因为指示函数为1时 `y=z`。由此

\[
E_P[(Y-\mu)S_z(Y)]
=E_P\!\left[(Y-\mu)\frac{\mathbf1\{Y=z\}}{p_z}\right]
-E_P[Y-\mu]=z-\mu.
\]

它恢复已完成的点替换变化率。在二元例中，`S_1=(Y−μ)/μ`、`S_0=−(Y−μ)/(1−μ)`；所以点替换路径与 logit 路径即使方向相关，其速度和 score 仍不同。

两个支持点的参考概率均正，意味着上述点替换公式可以在0附近向负 `t` 延伸而保持概率为正。普通混合解释使用 `0≤t≤1`；双侧正则路径使用局部延伸，两者应在技术说明中衔接。不能将这种离散支持上的合法性推广到连续分布中的任意点质量污染。

### 4. GLM 回归与 TMLE fluctuation

对 Bernoulli-logit 回归，设线性预测子 `η=x^Tβ`、条件均值 `Q=expit(η)`。固定设计向量 `x` 后，单观测条件对数似然的系数 score 为 `x(y−Q)`。这里只须一行链式法则：对 `η` 求导得到 `y−Q`，再乘 `∂η/∂β=x`。其他 GLM family 或 link 可能包含不同的导数与方差因子，因此正文应明确写“logistic 回归的 score”，不宜泛称“所有 GLM 的 score”。

TMLE 固定初始拟合后，沿

\[
\eta_\varepsilon(a,w)
=\operatorname{logit}\widehat Q_{\mathrm{init}}(a,w)
+\varepsilon H(a,w)
\]

调整一个系数。初始线性预测子是系数固定为1的 offset；`H` 是固定协变量；`ε` 是唯一待估系数。对单观测条件对数似然求导，

\[
\partial_\varepsilon\ell_\varepsilon(o)
=H(a,w)\{y-\widehat Q_\varepsilon(a,w)\}.
\]

此 score 是完整风险差 EIF 的结局残差项。第0章已定义的经验基线标准化保证

\[
P_n\{\Delta_\varepsilon-\widehat\psi_\varepsilon\}=0,
\]

因此其经验平均才与完整 EIF 的经验平均相等。不能把逐观测 `H(Y−Q_ε)` 直接写成完整 EIF，因为后者还含 `Δ_ε−ψ_ε`。

## 正文集成时应检查的具体边界

1. 区分 `E_P s=0` 的模型恒等式与拟合后 `P_n s_{\widehatβ}≈0` 的样本方程。后者需要说明无惩罚、有限内点解及数值收敛；极大似然的分离边界例外可放入技术说明。
2. 在当前参考分布处计算导数，只证明该参考处的数学关系；参考 `P=P_n` 不使未知真实 `P_0` 成为已知。
3. 截距模型中样本残差平均为0来自拟合中心；它不意味着每人的残差为0，也不意味着估计量恰等于总体目标。
4. 回归系数是向量时，score 和信息量相应为向量与矩阵。第0章可只说明维度，避免把一维 `I^{-1}s` 直接套作风险差目标 IF。
5. 一般统计模型中的梯度必须对允许的路径满足导数关系；均值零条件本身只提供中心化，不能单独证明某函数是目标 IF。
6. 两章新增英文统一用 `generalised`、`parameterisation`、`centring`、`standardisation` 等 British spellings。
