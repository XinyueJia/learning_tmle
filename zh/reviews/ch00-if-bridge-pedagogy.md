## 冻结稿的具体核对

| 教学问题 | 现稿中的回答与判断 |
| --- | --- |
| §4提出的分布误差怎样进入目标误差？ | §5.1固定真实人群、真实风险与真实ATE，只把一项拟合风险由0.80改成0.82。先算拟合处理风险0.66，再减对照风险0.45得0.21，最后减真实0.20得误差0.01。每一步都能用前文的标准化运算复算；不是先宣布IF存在再要求读者接受用途。 |
| 改拟合是否会被混成换目标人群？ | 开头明确“没有改变真实人群或干预效果”，引入拟合分布标签，并让人群比例及其余风险保持不变。它与§6改变目标人群比例的实验是不同操作，文中已经区分。 |
| 数字桥为什么要有两个方向？ | §5.1主文算处理风险高估，紧接着解释对照风险高估时由ATE里的减号改变方向。`fit-error`源码将两个互不叠加的单项错误并排：同样2pp输入误差分别变成+1pp、−1pp目标误差。图注还区分精确坐标计算与完整ATE IF。它让读者看到“作用取决于哪一项”，而不只是看到总误差。 |
| 单次拟合误差是否误称bias？ | 公式回看与图注均说明这是一套拟合结果的误差，尚未对重复抽样平均，不能直接称统计偏差。真实P与拟合分布、0.02与0.01、概率差与pp均有本地提示。 |
| IF为什么是函数？ | §5.2先指出不同记录类型的占比会变化，再提出输入记录类型、输出带符号敏感性值的规则。随后要求同一函数与不同合法方向配合，实际表示目标变化；任意打分不构成IF。最终稿补明下一章固定“所有旧权重同比缩小，再把腾出权重加给选定类型”的操作，比较不同记录时采用同一减权规则。这里不要求预先记忆ATE公式。 |
| 是否混成个体因果效应？ | §5.2明确输出是分布方向对目标的局部作用，不是这个人的处理效果。图的职责同样保留这个边界，不展示已知的个体反事实。 |
| 为什么从分布敏感性走到抽样误差？ | §5.3重新引入“换一批患者”，将记录比例与估计结果的波动连接起来，再提出各条贡献平均加剩余项的结构。主文和图都明确这一桥梁有额外条件，任意回归/代入估计不自动满足；没有把§5.1某项风险的精确线性当成一般误差分解。 |
| 为什么还要讨论efficient？ | §5.4先比较同一目标、同样样本量的估计规则可能具有不同的重复抽样波动，之后才引入统计效率和给定模型。EIF方差最小的作用通过§5.3的样本平均桥解释，而不是独立堆一个名称。 |
| regular与渐近是否突然出现？ | 在命名之前，已给出重复抽样、样本增大、主要波动和“恒报20pp”的具体反例。因此正则估计量及渐近方差有明确要回答的问题。恒报20pp只用于解释不能只凭一点恰好无波动来比较效率，不被当作完整regular定义或效率证明。 |
| 章节是否仍为概念导读？ | §5.2、5.4、5.5分别将正式IF计算、模型内有效性和估计方法构建交给后续章节；只给用途、条件与核对路径，没有提前要求ATE EIF完整证明。AIPW/TMLE是后续路线图，未把样本方程为零说成无偏或有效推断的充分条件。 |

## 两项局部建议

1. §5.2先说某类记录多一点、其他记录相应少一点，再把输出说成“这种分布方向”的敏感性。仅指定增加哪类记录，还没有唯一指定从别处怎样减。建议就地提示下一章会固定一种明确替换规则，例如先让全部旧权重按同一比例减少，再将移出的权重交给选定类型。随后仍保留一般IF与不同方向配合的解释。此建议只澄清“记录→方向”的连接，不要求在本章给出ATE IF公式。
2. 新主文已保留IF、function、bias、统计模型、统计效率、EIF、regular estimator、asymptotic variance与后续方法的英文。为遵守首次术语对应约定，可在§5.2“一阶”的首次解释、§5.3“剩余项”、§5.4“方差”首次用于正式解释处分别补 first-order、remainder、variance；中文已经提供相应用途，不需为英文另开定义段。

最终源码复核：以上两项均已处理。§5.2现已明确下一章将固定共同的旧权重缩小规则，再将腾出的权重加给选定类型；并补入first-order。§5.3补入remainder，§5.4补入variance。新增短句没有将方向查表说成一般IF的完整证明，仍保留同一函数与不同合法方向配合的要求。两项关闭。
