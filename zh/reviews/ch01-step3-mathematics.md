## 从目标与有限支持独立推导

原支持为三个不同分数0、1、3；原概率p=(.2,.5,.3)，质量和为1，μ=Σ_j p_j y_j=1.4。选定已有支持点z，路径概率q_j(t)=(1−t)p_j+t I{y_j=z}。先以新概率计算目标，再与原目标比较：

```
Ψ(P_t)=Σ_j y_j[(1−t)p_j+t I{y_j=z}]
       =(1−t)Σ_j y_jp_j+tΣ_j y_j I{y_j=z}
       =(1−t)μ+tz
       =μ+t(z−μ)。
```

其中指示符和等于z，须沿用本章“z为已有的三个不同取值之一”的限制。对非零合法t：

```
[Ψ(P_t)−Ψ(P)]/t
= [μ+t(z−μ)−μ]/t
= t(z−μ)/t
= z−μ。
```

起点导数是该差商在非零合法t趋零时的极限，不能在原分式直接代入0，也不能把t=.1的实际变化直接称为IF。有限正支持保证0附近存在合法双侧t；一般连续分布不能无条件沿用点污染为regular路径的结论。此处均值沿路径线性，所以有限非零差商精确等于导数，而不只是数值近似。

定义D(z;P)为该起点变化率，得到一个以分数z为输入、原分布P为参照的函数。三个值为D(0;P)=−1.4、D(1;P)=−.4、D(3;P)=1.6。单个z的计算只是函数的一个值；三个输入和对应输出一起描述本章支持上的函数。

## 从固定函数到随机变量

小写z是我们逐个选定的输入；大写Y是按原P随机抽到的分数。将随机输入Y送入同一个固定函数，得到D(Y;P)=Y−μ：

| 原随机分数Y | 0 | 1 | 3 |
|---|---:|---:|---:|
| 输出D(Y;P) | −1.4 | −.4 | 1.6 |
| 输出概率（仍按原P） | .2 | .5 | .3 |

本例减去常数的一一映射没有合并支持点，故每条输出保留对应输入的概率。输出可能为负，但概率仍非负且和为1。图不能用D值作为概率高度，不能因抽到某分数而把原概率换成污染后的q。

这里的D是目标对分布扰动的变化率，不是某个人的分数改变或个体因果效应，也不是把一条观测加入有限样本所造成的实际均值变化。它也不等于路径score：若提到score，应明确它描述概率相对变化而非直接描述目标的变化；本章无需预先证明后章的一般score配对或canonical结论。

## 均值零的两条完整计算

### 数值加权

```
E_P[D(Y;P)]
= .2(−1.4)+.5(−.4)+.3(1.6)
= −.28−.20+.48
= −.48+.48
= 0。
```

未加权D总和是−.2，未加权平均是−.2/3，都不等于0。负向贡献的长度应按绝对值画、从共同零线向左；正项从同一零线向右；负项合计与正项长度相等。零期望不等于各项都为0。

### 一般有限求和

```
E_P[D(Y;P)]
= Σ_j p_j(y_j−μ)
= Σ_j(p_jy_j−p_jμ)
= Σ_j p_jy_j−Σ_j p_jμ
= Σ_j p_jy_j−μΣ_j p_j
= μ−μ×1
= μ−μ
= 0。
```

提出μ因为它是原分布确定的共同常数，不随求和下标j变化；μΣp=μ还使用了概率质量和为1。只说“期望的线性”不足以替代本轮要求的完整主线。对应图必须分别展示Σpy=1.4、Σp=1和μΣp=1.4；质量1与分数1.4单位不同，不能将两个等高概率条误作证明。

均值零是此IF的性质，**不足以认定任意函数为IF**。例如恒零函数也均值零，却不能表示z=3时变化率1.6；2D均值也为零，却给出错误的变化率3.2。判定必须保留其先前导数来源；不必在本章提前要求证明canonical。

## 原参照分布不能偷偷改变

固定旧函数D(y;P)=y−1.4，将平均权重改成z=3、t=.1的q=(.18,.45,.37)，则

```
E_{P_t}[D(Y;P)]
= .18(−1.4)+.45(−.4)+.37(1.6)
= −.252−.18+.592
= .16。
```

一般地Σq_j(y_j−μ)=Σq_jy_j−μΣq_j=Ψ(P_t)−μ=t(z−μ)。这不是重新中心化：若改用D(y;P_t)=y−1.56，该新函数在P_t下又有零平均，但已改变了函数。对照图应始终保留旧输出−1.4/−.4/1.6，只更换概率；不能把输出改成−1.56/−.56/1.44后仍声称其和为.16。
