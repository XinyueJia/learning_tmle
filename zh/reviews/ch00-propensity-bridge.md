## 第一轮：建议先解释任务，再命名函数

当前第0章已区分 Q 的死亡风险预测与 g 的处理概率预测，但 g 在任务尚未出现时先进入定义表；“为后面的残差加权与误差校正提供概率”又把其用途推迟到 IF 后。建议在现有 Q/g 表前增加同一 RHC 任务：接受 RHC 与未接受者的基线构成可能不同；Q 路线先预测给定基线下两种处理的死亡风险，再按同一目标人群平均；另一条路线保留实际 A、Y，用实际接受该处理的机会为记录赋权，使两臂分别代表共同的基线人群。为了计算后一条路线的权重，先要估计“这类患者接受 RHC 有多常见”。此时再引出 g 与 propensity score，自然得到输入 W、输出处理概率的意义。

建议顺序：RHC 两组构成问题 → Q/g 各任务及既有真实患者调用图 → 识别条件 → propensity score 如何用于 IPW 与 PSM → 已可计算的 g-computation / IPW 点估计 → 为什么还研究 IF。不用 AIPW 公式作推导起点。g-computation 名称中的 g 不意味着该估计必须拟合本书的处理机制 g，可用一句明确两者。

## IPW：先总体恒等式，后样本估计

先固定观测分布 P，且目标人群内 0<g(W)<1（几乎处处）。二元 Y 可积。保持与本章一致的 Q(a,w)=E_P[Y|A=a,W=w]、g(w)=P(A=1|W=w)。总体恒等式为：

$$
E_P\!\left[\frac{AY}{g(W)}\middle|W\right]
=\frac{P(A=1\mid W)E_P[Y\mid A=1,W]}{g(W)}
=Q(1,W),
$$

$$
E_P\!\left[\frac{(1-A)Y}{1-g(W)}\middle|W\right]
=Q(0,W),\qquad
\Psi(P)=E_P\!\left[\frac{AY}{g(W)}-\frac{(1-A)Y}{1-g(W)}\right].
$$

就地回看应解释：A 与 1−A 是选择实际两臂的 0/1 指示；Y 是实际结局；条件期望先固定 W；分母分别是接受及未接受 RHC 的概率；两臂先恢复相同 W 构成，再作风险差。该等号是观测分布的代数事实；等于因果 ATE 还需前文识别条件。

可以另给一句基线平衡恒等式 E_P[A f(W)/g(W)]=E_P[f(W)]，控制臂同理，其中 f 是任何可积的基线汇总函数；若引入，应解释 f，避免新增符号反而增加负担。若不展示公式，用真实 sex 八格的分层计数即可。sex=x 层 n_x 人，RHC n_1x 人，层内频率 ghat(x)=n_1x/n_x 时，加权人数 n_1x/ghat(x)=n_x；控制臂同理。此有限表恒等式仅限每层两臂均有人且使用相同层内频率的构造；连续、多变量 logistic 拟合不自动逐层精确平衡。不能把性别标准化的关联称为已识别临床 ATE。

样本规则应单列为 Horvitz–Thompson 型 IPW：

$$
\widehat\psi_{\mathrm{IPW}}=\frac1n\sum_{i=1}^n
\left[\frac{a_i y_i}{\widehat g(w_i)}-
\frac{(1-a_i)y_i}{1-\widehat g(w_i)}\right].
$$

回看 n、i、a_i、y_i、w_i 是本批记录及其下标，帽号是样本拟合；1/n 是按原目标样本总人数平均。使用每臂权重和作分母的是另一种 Hájek 型正规化规则；不能将两者在有限样本中写成同一个等号。估计 g 不保证无偏、两臂权重和恰等于 n、协变量完全平衡，或估计值一定在 [−1,1]；两种处理的稀少概率均会放大权重。截断、删人、稳定化或换目标人群需要显式说明。

若配真实患者图，权重作用于实际 Y，不能作用于两个预测风险而仍称同一个原始 IPW；保留 a_i 与 y_i 观察列、ghat 列、两臂非负权重和两臂贡献列。显示前6人仅为预览，汇总必须用全部5735人。图不应先使用 IF 或 H 残差项来解释 IPW。

## PSM：同一倾向评分，另一项任务

propensity score matching（PSM，倾向评分匹配）用 ghat(W)寻找另一臂处理机会相近的比较者。每名已接受 RHC 者匹配未接受者的常见设计，以已处理者为目标，通常对应 average treatment effect in the treated（ATT）：

$$
\psi_{\mathrm{ATT}}=E[Y^1-Y^0\mid A=1].
$$

回看上标是两种策略，条件 A=1 是实际接受者，期望只对该目标人群平均。需说清楚：PSM 本身不固定 estimand；双向匹配、全匹配等设计可服务其他目标。若无法匹配的 RHC 患者被删去，所分析的处理者人群也随之改变，不能继续无条件称原始全部处理者 ATT。ATE 的总体 IPW 中处理臂与控制臂分别用 1/g 与 1/(1−g)，不能把它当作 ATT 的权重规则。

精确真实 propensity score 在总体中的 balancing property 是 A 与 W 在给定 g(W)后独立；样本中的估计分数相近，不能保证 W 每项相同，更不能消除未测混杂。第0章可以不增独立公式，直接解释并要求检查匹配后的基线平衡、共同支持（common support）、匹配距离、是否替换和被排除者。没有实际匹配算法与诊断时只作设计介绍，不生成“已匹配患者”或匹配效应数值。

建议以三行比较收束：Q / g-computation 预测死亡风险并对共同 W 平均；g / IPW 预测实际处理机会并重加权实际 Y；g / PSM 依处理机会寻找比较者，目标人群随设计而定。三条路线都须独立论证因果识别。

## 参考文章可借鉴之处与必须修正的内容

可借鉴其“组间构成 → 加权 → 两模型 → 误差分析”的叙事直觉，不能直接采纳其公式或结论。该文没有展开 PSM，因此本次匹配桥梁应自行说明目标人群。

- 参考文 E[Y/e(X)] 缺处理指示，不能作为一般处理臂均值或 ATE 的完整 IPW 公式；对照臂也需其自己的 1−e(X)。
- 参考文在 CATE 记号外对 X 求平均，实际混入总体平均目标；本章保持 ATE 与条件效应分开。
- 参考文“Q 准确使残差逐项为0”不成立；条件均值正确只使条件期望残差为0。g 正确也不会恢复每人的两个已观测潜在结局。
- 参考文将 Neyman orthogonality 与 double robustness 直接等同，并暗示更快收敛，不能照搬；当前桥梁无须提前教授这组概念。
- “还原真实分布”“无偏”等说法过强。IPW 的用途是按指定观测基线构成重新表示两臂，不会自动解决未测混杂、选择或时间窗问题。

## 与实际接口一致的边界

`rhc.js` 的 gFit 仅以基线设计预测 A；qFit 另拼接实际 A 拟合 Y，再分别拼接0/1预测。H=1/g 或 −1/(1−g) 已存在，用于后续加权残差，但 prepareRhc 当前返回的是 g-computation、初始残差 score 与 AIPW，未独立返回原始 IPW 或 PSM。新增图若显示 IPW，应据实际 g 与实际 A/Y 单独计算；不得把已有 aipw 值标成 IPW。该文件检查拟合边界并显式失败，没有隐藏截断；文案须保持这一事实。

`rhc-model.js` 是原始八格计数导出的经验参考分布，不能冒充未知 P0。若图用它展示 sex 分层 IPW 的精确平衡，应标注冻结经验频率；若用 `rhc.js` 的完整 W logistic 预测，应标注估计概率，并与精确分层示例区分。

### 数学与教学边界逐项关闭

- g 的任务先于符号定义出现：先给同一真实队列的两组sex构成，再解释预测处理机会如何用于选择比较记录或加权。Q预测死亡、g预测实际处理的事件清楚分开，既有全W预测图与新增sex频率加权图也有各自标签。
- 目标仍是按同一目标W分布平均的标准化风险差；sex计算明确称性别标准化关联。没有从观察到sex构成不同直接断言它已构成因果混杂。
- 总体IPW恒等式在固定P及正值性下展开，先按A分解条件期望，再用全期望法则汇总。两臂指示、实际Y、条件概率与风险的分工正确；其因果解释另接§3.2条件，没有把可交换性当作观测分布代数的前提。
- 样本式使用全样本n作分母，是Horvitz–Thompson型规则。折叠说明正确区分Hájek型正规化；二者在本例相等的原因是sex饱和频率下每臂权重和等于n，未向一般多变量logistic拟合推广。
- PSM解释为寻找倾向接近的比较记录，同时明确匹配设计决定目标人群，ATT与完整人群ATE有别，删去无法匹配处理者会改变朴素匹配分析代表的人群；没有声称已实际完成匹配，也没有伪造匹配效应数值。
- 新增公式均有就近符号解释。图内Female/Male标签为数值x=0/1提供对应；分层人数、拟合帽号、患者下标、两臂选择、全样本分母及概率差单位有回看。未把Y的拟合条件均值当逐人真实潜在结局。
