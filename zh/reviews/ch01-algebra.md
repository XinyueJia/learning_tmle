## 独立基准与必须展示的中间层

目标由更新后的概率定义：Ψ(P_t)=Σ_j y_j p_j(t)，其中原支持为三个不同取值0、1、3，原概率为.2、.5、.3，原均值μ=1.4。路径为p_j(t)=(1−t)p_j+t I{y_j=z}；z限定为已有支持点，且t须使新概率合法。

### 具体选择z=3

从定义直接分配乘法，可得：

```
0[.2(1−t)] + 1[.5(1−t)] + 3[.3(1−t)+t]
= 0−0t + .5−.5t + .9−.9t+3t
= .5−.5t+.9−.9t+3t
= (.5+.9)+(−.5−.9+3)t
= 1.4+1.6t。
```

逐项依据为0×.2=0、1×.5=.5、3×.3=.9，且3乘括号内的新增t产生3t。0和0t因零乘法归零；剩余常数相加为1.4，t的一次项系数相加为1.6。这是展开及合并同类项，不能说所有t项互相消掉。须让读者看见3t来自新增权重，而非把原3分组替换前的整个概率丢掉。

### 一般支持点z

先以I_j暂记I{y_j=z}。每项的分配为：

```
y_j[(1−t)p_j+tI_j]
= y_j[p_j−tp_j+tI_j]
= y_jp_j−ty_jp_j+ty_jI_j。
```

逐项求和后才拆成三个和，再把对j不变的t提出：

```
Σ_j[y_jp_j−ty_jp_j+ty_jI_j]
= Σ_j y_jp_j − Σ_j ty_jp_j + Σ_j ty_jI_j
= Σ_j y_jp_j − tΣ_j y_jp_j + tΣ_j y_jI_j。
```

这一步只使用有限求和的分配性质与共同因子，不需要概率求导法则。不能将第三个和直接换成z而跳过指示符的实际求值。

在本章三个不同取值中，选定z只使一个指示符为1，其余为0；因此

```
Σ_j y_j I{y_j=z}
= 0 I{0=z}+1 I{1=z}+3 I{3=z}
= z。
```

可分别核算z=0、1、3时为0、1、3。z=0时选中的项虽然为0，但指示符仍为1，不代表没有选中项。该和没有乘p_j，不能误写成z p(z)；若z不在现有支持，原三项指示符和等于0，必须另加新支持行，因此本章“已有取值”限制不能省去。

代回原均值定义Σ_j y_jp_j=μ，所得μ−tμ+tz可写为μ+t(−μ+z)=μ+t(z−μ)。这里是将后两项的共同因子t提出，不能说−tμ与tz一般相消。

### 实际变化、差商和起点导数

原目标Ψ(P)=μ，因此应把实际变化明确写为：

```
Ψ(P_t)−Ψ(P)
= [μ+t(z−μ)]−μ
= (μ−μ)+t(z−μ)
= t(z−μ)。
```

这一步才发生μ−μ的真正相消。对非零且合法的t：

```
[Ψ(P_t)−Ψ(P)]/t
= [μ+t(z−μ)−μ]/t
= t(z−μ)/t
= z−μ。
```

t≠0是约去t的条件；原差商在t=0处没有定义。起点导数是非零合法t趋近0时的极限，不能写成把t=0直接代入差商后约分。原有限正支持保证0附近有合法双侧路径，故此处可使用通常的起点导数；均值线性使非零差商恰好恒定，不应推广为所有目标的大步长精确性。

### 2.2：一般式与指示符——通过

代入时三个和的角色分别标为μ、μ、z，接着μ−tμ+tz→μ+t(−μ+z)→μ+t(z−μ)，提共同因子与交换顺序都正确，没有把−tμ与tz称为相消。

正文先减去Ψ(P)=μ，依次展示去括号、将μ−μ并置、归零及留下t(z−μ)。这里的“完全相消”准确指外侧原均值常数，不是消掉t内的−μ。
