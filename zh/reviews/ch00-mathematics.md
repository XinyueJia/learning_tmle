## 因果问题、识别与统计计算的独立基准

### 因果目标先于算法

先固定目标人群、两种具体干预、结局及随访时间。令二元A为干预，Y为结局指示；Y^a是同一目标人群在干预a下的潜在结局，不是从每人身上同时观察到的两个标签。我们可以分别问总体干预风险E[Y^1]、E[Y^0]，或风险差ATE=E[Y^1−Y^0]。ATE是人群平均，不代表每个人都有同样效应。CATE(x)=E[Y^1−Y^0|X=x]固定子人群x，不能再外层平均X后仍叫该x的CATE。

观察数据只包含实际A对应的Y和基线X。Q(a,x)=E[Y|A=a,X=x]是观察条件均值；不能因为它来自回归预测，就自动等于E[Y^a|X=x]。两者相接依赖：干预定义明确和一致性Y=Y^A；给定所用干预前X后无未控制的混杂（条件交换性）；目标人群各组有机会接受两种干预（positivity）。如果识别失败，EIF不能从观察分布补出缺失的因果信息。

在这些条件下，先组内再组间加权：

```
E[Y^a] = Σ_x P(X=x) E[Y^a|X=x]
       = Σ_x P(X=x) E[Y^a|A=a,X=x]
       = Σ_x P(X=x) E[Y|A=a,X=x]
       = Σ_x P(X=x) Q(a,x)。
```

这里每一步分别用重复平均、交换性及一致性；positivity使目标组的条件量可由观察数据识别。于是identified ATE=Σ_xP(X=x)[Q(1,x)−Q(0,x)]。第0章可用文字/数值解释，不要求读者先会条件期望定理或微积分，也不需给ATE EIF公式。

### 统计functional与拟合算法

给定目标后，Ψ是把一整套观察分布P映射为目标数的计算规则；在识别条件下，该数有指定因果解释。未知真实P不是一份数据表，也不是任意指定的算法。统计模型说明允许哪些分布及其限制；拟合算法说明如何用样本选出一套概率或条件均值。经验分布P_n给每条样本记录1/n权重，拟合分布/拟合Q,g来自估计规则；它们均不因被画出就等于真实P。

estimand是要估的总体目标，estimator是依样本计算的规则，estimate是给定一份数据得到的数。模型中给定真概率后直接算出的.20是教学总体目标值，不是已经运行某估计器的一次样本estimate。实验没有抽样时，不能把显示的总体识别数称为已证明无偏的估计结果。

## 本例数值：独立有理数验算

取X二元、r=P(X=1)，故PX=(1−r,r)；固定Q0=(.70,.20)、Q1=(.80,.50)，各组风险差(.10,.30)。因此：

```
risk0 = .70(1−r)+.20r = .70−.50r
risk1 = .80(1−r)+.50r = .80−.30r
ATE   = .10(1−r)+.30r = .10+.20r。
```

| r | 全部干预0风险 | 全部干预1风险 | ATE | 观察分配g=(.2,.8)的未经调整差 | 随机分配g=(.5,.5)的未经调整差 |
|---|---:|---:|---:|---:|---:|
| .2 | .60 | .74 | .14 | −7/340≈−.0205882 | .14 |
| .5 | .45 | .65 | .20 | −.04 | .20 |
| .8 | .30 | .56 | .26 | 23/340≈.0676471 | .26 |

独立未经调整差依据Bayes重算，而非以目标值代替：

```
E[Y|A=1] = Σ_x p_x g_x Q(1,x) / Σ_x p_x g_x
E[Y|A=0] = Σ_x p_x(1−g_x)Q(0,x) / Σ_x p_x(1−g_x)。
```

默认r=.5时治疗组的X权重(.2,.8)，对照组(.8,.2)，观察均值分别.56/.60，所以naive=−.04；两个干预风险却按共同目标人群(.5,.5)计算为.65/.45，ATE=.20。随机分配时两组X权重均为目标人群PX，未经调整差才等于ATE。这是给定教学分布下的总体计算，不是随机分配保证每一有限样本均衡或无误差。

本审查者已用Python Fraction按上述原定义实际执行六个(r,g)组合，表中有理数与小数均核对无误。此处仅是待实现的独立基准，不代表实际chapter0-data或实验已通过。

界面目标切换ate/risk1/risk0应分别选择上述三种functional；改变r会改变目标人群组成及相应目标值，不偷偷改变Q或分配模式。assignment切换只改变g；同一r下三个干预目标值不变，但观察治疗/对照组组成与未经调整差会变。风险与风险差均为概率尺度，显示百分数/pp须明确；.20风险差为20个百分点，不是20%的相对风险变化。

## IF、估计误差及efficient的概念边界

1. IF先是目标对合法微小分布变化的一阶敏感性描述，固定目标、模型及参考分布。它不是“每个人的因果效果”，也不是算法自动修复一切误差的按钮。
2. 从分布敏感性走到估计量误差须有条件：对合适的渐近线性估计规则，在余项够小等条件下，主要估计误差可写为观测贡献的样本平均。此时估计量的影响函数与目标的梯度之间有联系；不能说任意估计器的误差都等于EIF平均、对有限样本精确，或任何拟合算法都会自动得到该展开。
3. efficient指在给定统计模型和regular渐近比较范围内的精度/方差界；不是运行更快、有限样本每次最准确、因果识别保证或修复未测混杂。给定目标/模型下的canonical gradient需满足方向表示和模型限制；均值零本身不够。
4. semiparametric可直观解释为低维目标配合灵活的未知分布/干扰函数；这些仍受概率、支持、识别及模型假设限制，不是任意函数均可或所有functional必有IF。有限二元演示自身是有限维模型，是理解一般问题的计算窗口，不能因出现Q/g两个函数就断言该有限模型具有无限维未知量。
5. 可预告IF帮助设计一阶修正、理解波动和标准误；有效推断还需数据结构、positivity、拟合收敛与余项/经验过程控制等条件。第0章不必展开这些技术，但不能把其结论改成无条件承诺。

- 开头将外层E_X平均后的总体量称为CATE：应区分固定x的CATE与再平均后的ATE。
- 声称Q正确会令每条残差为0：真Q只保证相应条件平均残差为0，个体Y仍可波动。
- 声称g正确会使每条A/g权重消失，逐项变成同时可见的Y^1−Y^0：权重抵消是条件期望中的代数，不是逐条观测的消除，也不会同时观察两种潜在结局。
- 将经验targeting方程为0直接说成无偏：经验约束不保证真总体偏差为0，余项与拟合错误仍需控制。
- 把任意点质量混合都当一般regular路径，或沿一条路径可导便认定完整pathwise differentiability：有限支持的合法性不能无条件搬到连续分布，方向族及连续线性表示仍有要求。
- 将任意敏感性梯度直接称为EIF，或均值零当作足够条件：模型合法方向、表示和效率比较不能省略。
