# 教程讲解风格指南

本指南适用于整份教程的后续撰写和逐章修订。读者只需基础应用生物统计经验；正文以中文为主，英文采用 British English spellings。讲解方式参考用户指定的本地文章，来源与使用边界见 [风格来源记录](../reviews/style-reference.md)。借鉴的是问题组织、具体示例与推导之间的衔接，不复制原句、夸张修辞或数学结论。

## 先让读者知道为什么需要下一步

每节开头先回到一个能够具体回答的问题：要比较谁、平均什么、改变哪部分数据、最后希望得到哪个量。先说明实际含义，再命名 estimand（目标量）；后文更换问题或目标人群时重新提醒，不能让读者只靠符号变化猜测。

让一个自然疑问推动下一段。例如，已经能比较两组平均值，为什么还要按基线特征分组？已经能按组计算，为什么还要改变概率权重？先用当前例子暴露问题，再解释新工具解决了哪一部分。问题应由前一步的结果引出，不连续堆砌设问，也不把读者的不理解归因于能力不足。

介绍一个看似合理的方案时，先说明它为何有吸引力，再用可核对的具体差异说明不足。区分“没有回答当前目标”“在某些条件下成立”和“计算错误”；不能为引出新方法而笼统否定组间比较、回归或加权。

## 先算出一个例子，再写一般规则

先用小型离散分布、有限个组或清楚列出的记录完成一次计算，让读者知道输入、每一步运算及输出。随后用符号压缩刚完成的操作；不要同时引入新符号、新问题和新模型。

数字例子应能逐项检查：概率来自哪里、各组贡献如何算、分子和分母各包含哪些记录、单位是什么。由概率模型计算出的总体结果与一份随机样本的结果必须分清。参数只由共享计算模块提供，图表、实验与正文围绕同一模型解释，避免另建一套默认值。

每个关键步骤配有可计算的图示或表格。读者应能沿着记录、概率、加权贡献和总和复算；变化图要明确固定什么、改变什么。图中的面积、长度、颜色、箭头和坐标各自表达的量就地说明，不让装饰承担没有定义的数学含义。图示结论由真实计算驱动；近似结果须标明近似，不能用目标公式伪造验证它的精确曲线。

## 公式解释本次运算，不考验记忆

每组公式之前，用一句话说明本次要算什么以及为什么要这样算。连续推导中，代入、分配、拆开求和、提出常数、相消及非零约分都要写出足够的中间步骤；不能用“显然”跨过读者尚未见过的运算。

在每组独立公式紧邻处加入默认可见的局部回看，遵循 [课程约定](COURSE_CONTRACT.md)。正文使用 `> **符号回看：** ... **这一步：** ...`，计算图使用共享的 `renderFormulaRecall(source)`。回看只解释当前出现的符号、单位和运算：随机输入与选定输入、原分布与新分布、固定基准与更新对象、索引与权重等按需选取。数值式也要说明各数的角色；不能只给纯符号式加提示。

回看不替代首次定义，也不提前引入主文还没有解释的术语。重复符号跨段出现时，可以再次简短提醒；不要求读者回到全章词典查找，也不在每幅图重放完整定义表。公式必须与邻近图、文字及其单位相符。

## 名称、条件与结论逐层到位

中英文术语首次出现时给出中文含义、英文名称以及它在当前问题中的用途，缩写随名称一起定义。后续保持名称一致；同一个英文词在不同语境有不同含义时，明确区别，例如路径 score 与 propensity score。新数学工具从一次具体运算引出，不假定读者已掌握求导、条件期望、内积或渐近记号。

每章可独立回看，首次正式解释的标准术语使用“中文（English）”，例如“泛函（functional）”，不要只给术语而漏掉对应英文。函数（function）与泛函（functional）、方向导数（directional derivative）与沿路径可微性（pathwise differentiability）须分别命名；英文不是中文释义或完整推导的替代品。后续重复无需每次附英文，公式中的符号仍就地回看。

先把观察到的分布目标讲清，再说明何种假设允许因果解释。区分条件于某组的量与对目标人群再次平均的量，区分总体加权恒等式、样本方程、极限结论及有限样本性质。介绍双重稳健、正交性或效率时，应给出各自的条件及需要验证的对象，不能用名称相互代替证明。

章节收尾回到开头的问题，指出目前已能计算什么、还剩哪个具体疑问，并解释下一章为何需要处理它。技术补充可以扩展一般条件，主线中的关键推导与限制仍须完整保留。

## 历史应用范围

第0章按本指南实施：从一个明确的二元结局比较问题出发，先列两类人群与各组风险，再区分目标人群、处理分配、两种干预风险及其差。用同一模型对照观察到的两组风险与目标量，让读者看出更换目标人群或处理分配时，哪些数会改变。先完成这些数值操作，再将“要估计什么”和“如何估计”交接给后续章节。
