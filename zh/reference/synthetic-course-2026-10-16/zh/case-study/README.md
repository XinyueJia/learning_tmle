# 固定RWS疗效再评价案例：数据与Julia运行说明

研究问题：同一适应证、同一治疗线且药物A/B均可选的晚期非小细胞肺癌新使用者，首次启动匿名已上市研究药物A，与首次启动活性对照药物B相比，12个月内疾病进展或全因死亡的风险差是多少？两者均为治疗；A=0不是不治疗。入组资格、初始用药与随访起点在首次给药日对齐，停药或换药后仍按初始分组继续记录结局。

X=0表示高基线预后风险，X=1表示低风险；本教学假定X已概括所需基线混杂。Y=1为12个月内发生进展或全因死亡，Y=0为已确认12个月内无进展且存活。每人最多计1次，不把进展次数和死亡次数相加；假定结局完整、准确可得，但不以未来完成随访作为入组条件。比较的是初始策略的固定时点二元风险差，不是持续用药效应、中位PFS或HR。

这里提供200条固定合成记录，不是真实世界数据（RWD）或真实世界证据（RWE），不能作为任何具体药物疗效或安全性的证据。频数刻意使经验概率等于原教学模型；通常随机样本并不会如此。完整研究要素和边界见第0章与源码中的zh/docs/RWS_CASE_PROTOCOL.md。

- `shared/data/rws-counts.csv`：按X、A、Y合并后的八行频数；n是该格人数。
- `shared/data/rws-records.csv`：同一数据展开成200行，id只是行号。
- 八讲合成数学演示读取同一文件。网页的分布机制实验可以改变假设参数，章末固定案例不会跟着改数据。

## 用Julia逐讲复算

以下命令均从包含`shared/`和`zh/`的项目根目录运行。完整交付包中的`shared/julia/EIFCase.jl`是可编辑的完整实现。`zh/julia/lessons/ch01.jl`到`ch08.jl`可独立运行，模块按BEGIN_CH01到BEGIN_CH08标出每讲新增定义；网页展开的代码从这些文件直接生成，不另维护一套演示代码。

在项目根目录运行：

```sh
julia --startup-file=no --history-file=no zh/julia/lessons/ch01.jl
julia --startup-file=no --history-file=no zh/julia/lessons/ch08.jl
julia --startup-file=no --history-file=no tests/julia/runtests.jl
```

只使用Julia及其标准库，无需安装TMLE包。脚本用自身目录定位CSV，从其他目录启动也可以；运行时须保留`zh/`与`shared/`的相对位置；单独一个lesson文件不足以运行。标签X/A/Y为0或1，而Julia数组索引从1开始，所以Q数组用`q[a+1,x+1]`。

第8讲既能手填epsilon，也能逐步二分；源码明确计算每组事件数与预测总数的残差、score及其根，然后更新四组预测，最后按经验X比例重新平均。计算不读取未知真概率。你可以给`zh/julia/run_case.jl`传入另一份符合当前有限正单元要求的计数CSV，核对输入变化后结果也会改变。

## 完成一次TMLE与完成有效推断

本例的初始结局模型故意只按处理A分组，保留一个需要修正的目标相关误差；一个epsilon更新不必恢复全部组内风险。手算目标是构造估计与检查经验方程，而非仅凭方程等于零宣布无偏或置信区间有效。

第7讲分别说明经验二阶矩、中心化方差与标准误的区别；第8讲更新函数后重新计算。显示的经验SE是计算演示，不能替代更新函数一致性、余项和抽样条件的验证。若追求有效统计推断，需要进一步选择足够灵活的拟合方式并论证这些条件。

## 结果的临床方向

本表未经调整的A减B风险差为−4pp；在教学识别假设下，以同一人群构成标准化得到+20pp，表示研究药A的进展或全因死亡风险更高。低风险患者更常启动A，使粗比较方向反转；活性对照/新使用者设计并不自动排除混杂。该复合终点包含死亡，但没有单独评价特定不良事件或药物安全性。
