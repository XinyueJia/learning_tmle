## 先把研究问题写完整

在同一适应证、同一治疗线且两种候选药物均可选的晚期非小细胞肺癌（non-small-cell lung cancer，NSCLC）成年人中，如果首次启动研究药物A，与首次启动活性对照药物B相比，12个月内疾病进展或全因死亡的风险相差多少？比较的是同一目标人群，风险差方向固定为A减B。

| 要素 | 本教学的约定 |
| --- | --- |
| 上市后背景 | 设想基于多中心常规诊疗数据库开展真实世界研究（real-world study，RWS）。本项目提供的是模拟这一问题的数据结构，不是真实世界数据（real-world data，RWD），也不构成真实世界证据（real-world evidence，RWE）。 |
| 人群 | 两种药物均有同一适应证/治疗线、均可选择的成年人；不将结果自动外推到所有癌症患者。两药及初始批准方案在教学中预先约定，药名不对应真实产品。 |
| 新使用者 | 在本教学中假定既往用药史完整，此前未使用A或B，现在开始其中一种；不是要求此前从未接受任何抗肿瘤治疗。真实项目需规定可观察的回溯窗口和具体洗脱标准。 |
| 活性对照 | A=1启动研究药物A；A=0启动同适应证活性对照药物B（active comparator）。A=0不是不治疗、安慰剂或未暴露于任何药品。数学变量A与药名A通过编码相连。 |
| 时间零点 | 每人的首次给药日是资格判定、初始用药分组与随访的共同起点（time zero）；X在给药前确定。不使用未来坚持用药或未来随访完整与否作为入组条件。 |
| 终点 | 首次给药后12个月内疾病进展或全因死亡的二元复合终点（composite endpoint）；进展按研究方案预先指定的统一影像/临床规则确认，死亡为全因死亡。合成表只保存判定后的状态，不含真实影像或日期。 |
| 计数 | Y=1为任一终点事件发生；Y=0为已确认12个月内无进展且存活。每人最多计1次，不能把一个人的进展和后续死亡计作两人。死亡已在终点内，不能当作普通删失。 |
| 后续用药 | 比较初始用药策略的效应（treatment-initiation effect）。随后按常规诊疗，停药/换药后也继续观察，并按最初启动策略分组。没有在估计坚持原药12个月的持续用药效应。 |
| 缺失简化 | 假定所有入组者的12个月终点状态完整、准确可得。这是观测模型假设，不是事后筛选“完成随访者”。真实失访不能删掉后当作无事发生，未知Y也不能编码为0；须扩展观测结构、识别假设和估计方法。 |
| 基线简化 | X=0高基线预后风险，X=1低；不是已验证的临床评分。教学假定X概括了全部必要基线混杂。真实RWS须根据问题选择分期、体能状态、既往治疗等信息，不能从二分标签推定混杂已控制。 |
| 汇总尺度 | 同一目标人群下的12个月终点风险差，单位为概率差；乘100显示为百分点（pp）。不是风险比、中位PFS、瞬时风险比HR或完整生存曲线。 |

## 同一个统计目标，没有更换数值答案

识别仍需一致性（consistency）、给定X的条件可交换性（conditional exchangeability）、正值性（positivity），以及本模型的完整观测和抽样条件。活性对照/新使用者设计可改善研究结构，但不能保证这些假设；EIF、AIPW和TMLE同样不负责证明它们。

O=(X,A,Y)，目标泛函仍为按p(X)标准化的Q(1,X)−Q(0,X)。Q(a,x)现在描述相应基线组、初始用药策略下的12个月终点事件风险。原共享DEFAULT_MODEL、八格频数和数学接口不变。总体模型与固定经验表仍明确分开；数据被刻意构造得经验概率等于教学总体概率，不把这一巧合当作一般抽样性质。

200人中116人发生终点事件、84人无进展且存活，全样本观察风险0.58。这是第1—2章均值目标，不是药物A与B的因果风险差。

教学默认模型中，A/B在同一人群下的标准化风险为0.65/0.45，差为+0.20；未经调整的两臂风险为0.56/0.60，粗差−0.04。X=1的低风险患者更常启动A，因此粗差混入了人群构成差异。这是本模型的机制设定，不是对某个药物真实处方习惯的断言。

正20个百分点意味着进展或死亡风险更高，属于不利疗效方向；不能改写为“A获益20%”。第8章TMLE的该数值也只是合成表在教学假设下的复算，不构成上市后产品结论。

## 疗效与安全性分开定义

用户本次选择以疗效再评价为主。死亡可涉及多种途径，但当前复合终点没有提供特定不良事件、药物归因或独立安全性比较。若后续分析严重不良事件（serious adverse event，SAE）等安全性终点，需要重新定义事件、时间窗与观测规则，获取对应数据并重设目标，不能只给当前Y换一个名称；当前结果不能据以给出完整获益–风险（benefit–risk）判断。
