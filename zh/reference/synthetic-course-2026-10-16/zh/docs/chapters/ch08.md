## 入口与推导计划

先保存 brief，再写正文。已读取 docs/SOURCES.md、docs/AUDIT.md 的独立乘积偏差段及 src/math.js 的 aipw/fluctuation/fluctuationScore/tmle API。承接第 7 章 RAL 的余项与经验过程要求，先从分布的一阶近似推导 one-step，不写成软件操作教程。

明确 P₀ 为真实分布、P̃ 为拟合分布、Pₙ 为经验分布，Pₙf=n⁻¹sum f。拟合协变量分布采用经验 X，plug-in=ψ(P̃)=Pₙτ̃。D̂=τ̃−ψplug+H_g̃(Y−Q̃(A,X))，H=A/g̃−(1−A)/(1−g̃)。从 ψ₀≈ψplug+P₀D̂ 到替换 Pₙ，得到 AIPW=Pₙ[τ̃+H(Y−Q̃)]；直接修正估计值，不改变初始 Q。

按 AUDIT 符号，以 e_a=Q̃_a−Q₀_a 定义总体 AIPW 偏差 B=E₀[(g̃−g₀){e₁/g̃+e₀/(1−g̃)}]。逐行条件期望证明正号，并写精确恒等式 ψ₀=ψplug+P₀D̂−B。于是样本误差=(Pₙ−P₀)D̂+B，再分解真 D₀ 项、经验过程差项和 B。

双重稳健性是整个 Q 或整个 g 正确使 B=0；正交性是在真 nuisance 处分别扰动时一阶偏差导数为零，解释关系而不声称普适等价。有效推断需 L²(D̂−D₀)→0、bounded positivity、拟合误差乘积 o_P(n⁻¹ᐟ²) 和 cross-fitting/经验过程控制。两边仅 O_P(n⁻¹ᐟ⁴) 不保证所需 little-o。

TMLE 更新条件均值：logit Q_ε=logit Q̃+εH。offset 是固定初始 logit，系数固定 1，只有 ε 拟合。Bernoulli log likelihood 链式求导得到 H(Y−Q_ε)，二阶导数 −H²Q_ε(1−Q_ε)。归零的是 Y score；X 部分由重新 plug-in 的定义归零，所以 PₙD̂*=0。方程零不是有限样本无偏证明，不需 Q* 每点等于真值。

## 实验接口

挂载点 `<div class="lab" data-lab="8"></div>`。独立 clone 默认真模型。[Q̃(0,0),Q̃(0,1)]=[Q₀(0,0),Q₀(0,1)]+[b,0.5b]；[Q̃(1,0),Q̃(1,1)]=[Q₀(1,0),Q₀(1,1)]−[0.5b,b]（下标0表示真实分布，首参数表示处理），b∈[−0.15,0.15]、默认 0.12；g̃=(1−λ)g₀+λ×0.5，λ∈[0,1]、默认 0.5。手动 ε∈[−1,1] 显示 trial Q_ε、score；自动 root 另调用 tmle 显示 epsilon、score、converged、iterations、更新 Q 与 OR/AIPW/TMLE。

预设：仅 Q 正确 (b=0,λ=1)；仅 g 正确 (b=0.12,λ=0)；两者错误 (0.12,0.5)；全对 (0,0)。所有估计值按 truth.px 积分，与样本算法 Pₙ积分严格区分；fit.px 不改变目标人群权重。

默认 OR=0.02、AIPW≈0.201978021978、TMLE≈0.234670322546，已同时 kernel 求值与独立枚举/求根核对。这个默认例能显示 TMLE 不一定更接近真值。预测题包含 Q 正确 root=0，g 正确 TMLE 恢复 0.20 但 Q* 不全正确，以及两者错误时不保证排名。

已完成双路径核对：共享 kernel 与独立 Python 八单元枚举、二分 root 均得到默认 epsilon≈0.283175496219227，TMLE≈0.234670322546071，AIPW≈0.201978021978022。kernel score≈−5.2e−18、iterations=5；更新 q=[[0.746625082011569,0.135282064580668],[0.864717935419332,0.486529856265047]]。

只有 Q 正确与全对的 kernel epsilon=0、score=0、iterations=0，三种总体值均为 0.20。只有 g 正确时 epsilon≈0.180072216555077、score≈8.3e−17、iterations=6，AIPW/TMLE 均为 0.20，更新 q≈[[0.784359910462058,0.124954125618356],[0.875045874381644,0.434268161698770]]，并不逐点正确。

独立直接计算偏差公式进一步得到初始 B≈0.001978021978022、更新 B(Q*,g̃)≈0.034670322546071。总体 root 时 score=0，TMLE−ψ₀=B(Q*,g̃)，是“方程零不保证偏差零”的具体反例。应用可用共享 fitFromOffsets(truth,b,lambda)、cleverCovariate(fit,a,x)、nuisanceBias(truth,fit) 驱动预设、权重和精确偏差对照。

总体实验中 true Q 内部、g 正且各组权重正，因此 score 严格递减、两端异号，有限唯一 root 存在。真实有限 Bernoulli 样本可能 separation，root 趋无限，不将总体结论泛化。TMLE plug-in 的概率差在 [−1,1] 内，但不因此获得推断保证。
